#  Projeto Contatos

Este é um sistema simples de gerenciamento de contatos feito com HTML, CSS e JavaScript.  
O projeto permite **criar, listar, atualizar e excluir contatos (CRUD)** consumindo uma API.

<img width="1897" height="649" alt="image" src="https://github.com/user-attachments/assets/b1fe931f-6bbb-4e2f-86f1-1dcf1ce563c1" />

---

##  Funcionalidades

-  Adicionar contatos
-  Listar contatos em tabela
-  Editar contatos existentes
-  Remover contatos

---

##  Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- API REST
